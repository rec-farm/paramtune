<task type="auto">
  <name>Task 1: Create autocomplete suggestion engine</name>
  <files>src/components/JsonEditable/utils/autocomplete.ts, src/components/JsonEditable/types.ts</files>
  <action>
Create a suggestion engine that analyzes the current cursor context and returns relevant suggestions.

**Implementation:**
1. Add types to types.ts:
   - `AutocompleteSuggestion { label: string; insertText: string; kind: 'key' | 'value' | 'keyword' }`
   - `AutocompleteContext { line: string; column: number; prefix: string; inString: boolean; afterColon: boolean }`

2. Create utils/autocomplete.ts with:
   - `getAutocompleteContext(text: string, cursorPosition: number): AutocompleteContext` - parses cursor location
   - `getSuggestions(context: AutocompleteContext, existingKeys: string[]): AutocompleteSuggestion[]` - returns suggestions
   - JSON keywords: `true`, `false`, `null` for values
   - Key suggestions: Common JSON keys like "name", "type", "value", "id", "description", "@extends"
   - Filter by prefix (case-insensitive)

**What to avoid:**
- Don't use external libraries - keep it pure TypeScript for bundle size
- Don't parse full JSON - use simple string analysis around cursor
- Don't show suggestions when cursor is in middle of existing text (only at word boundaries)
  </action>
  <verify>
Create a simple test in browser console:
```js

const ctx = getAutocompleteContext('{ "na', 5)
console.log(ctx) // { prefix: 'na', afterColon: false, ... }
console.log(getSuggestions(ctx, [])) // suggestions starting with 'na'
```
Build passes: `pnpm build`
  </verify>

  <action>
Wire up the suggestion engine and popup to the main editor component.

**Implementation:**

1. Create hooks/useAutocomplete.ts:
   - State: `suggestions`, `selectedIndex`, `visible`, `position`
   - `updateSuggestions(text, cursorPos)` - calls engine, updates state
   - `selectNext()`, `selectPrev()` - keyboard navigation
   - `acceptSuggestion()` - returns selected suggestion
   - `dismiss()` - hide popup

2. Modify keyboardHandlers.ts:
   - Add handlers for ArrowUp, ArrowDown when autocomplete visible
   - Modify Enter handler to accept suggestion if visible
   - Add Escape handler to dismiss
   - Export `createAutocompleteKeyDownHandler` that wraps existing handler

3. Modify JsonEditable.tsx:
   - Add useAutocomplete hook
   - Calculate popup position from cursor (use textarea.selectionStart + character width)
   - Render AutocompletePopup below/above cursor
   - Trigger updateSuggestions on text change and cursor movement
   - Handle suggestion acceptance (insert text, move cursor)

4. Update index.ts to export new types and hook

**What to avoid:**
- Don't trigger autocomplete on every keystroke - debounce to 100ms
- Don't show empty popup - only when suggestions.length > 0
