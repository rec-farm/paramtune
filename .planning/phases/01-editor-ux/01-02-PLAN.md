Create predefined light and dark themes and allow switching.

**Implementation:**

1. In optimizedSyntaxHighlighter.ts:
   - Rename DEFAULT_THEME to DARK_THEME
   - Add LIGHT_THEME with light-mode appropriate colors:
     - keys: 'text-purple-600 font-medium'
     - strings: 'text-green-600 font-medium'
     - booleans: 'text-orange-600 font-bold'
     - null: 'text-gray-400 italic'
     - numbers: 'text-blue-600 font-medium'
     - brackets: 'text-gray-700 font-bold'
     - commas: 'text-gray-400'
     - colons: 'text-gray-500'
     - extends: 'text-cyan-600 font-bold bg-cyan-100 px-1 rounded'
   - Export `getTheme(themeName: 'light' | 'dark'): SyntaxHighlightTheme`

2. In types.ts:
   - Update JsonEditableProps.theme type to 'light' | 'dark' (remove 'default')

3. In JsonEditable.tsx:
   - Accept theme prop (default to 'dark' for backwards compatibility)
   - Pass theme to SyntaxHighlightOverlay
   - Adjust container background based on theme:

     - light: bg-gray-100
