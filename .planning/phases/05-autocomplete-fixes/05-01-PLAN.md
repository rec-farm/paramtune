**Problem:**
1. When autocomplete popup is visible, Enter key always accepts suggestion (keyboardHandlers.ts:302-310)
2. Users can't create new lines without dismissing autocomplete first
3. Autocomplete triggers on every keystroke/cursor move, too aggressive

**Solution:**
- Track whether user has explicitly navigated suggestions (ArrowUp/Down)
- Only intercept Enter when `userHasNavigated` is true
- If user hasn't navigated, Enter creates new line and dismisses autocomplete
- Consider requiring minimum prefix length for suggestions

**Constraints:**
- Maintain Tab to accept (power user expectation)
- Keep 100ms debounce for suggestions
- Follow existing hook patterns
</context>
