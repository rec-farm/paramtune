<task type="auto">
  <name>Task 1: Extract diff engine to dedicated module</name>
  <files>src/lib/schemaDiff.ts</files>
  <action>
Create new file `src/lib/schemaDiff.ts` with:

1. Export types:
   - `DiffChange` - individual change with path, type (added/removed/modified/unchanged), old/new values
   - `DiffResult` - structured result with changes array and summary counts
   - `DiffOptions` - options like maxDepth, ignoreKeys

2. Extract and enhance from SchemaDiff.tsx:
   - `getNestedKeys()` - recursively get all paths
   - `getNestedValue()` - get value at dot-notation path
   - `calculateDiff()` - main diff function returning `DiffResult`

3. Add enhancements:
   - Type change detection (detect when value type changes, e.g., string → number)
   - Better array handling (detect array item additions/removals vs full replacement)
   - Path formatting helpers (for display)

4. Keep it pure TypeScript with no React dependencies (pure utility).

Avoid external diff libraries - the existing logic is sufficient and keeps bundle small. Only enhance what's there.
