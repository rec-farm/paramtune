  <files>src/components/JsonEditable/hooks/useOptimizedJsonEditor.ts, src/components/JsonEditable/components/ValidationStatus.tsx</files>
  <action>
Add a "validating" state to show feedback during the debounce delay:

1. In useOptimizedJsonEditor.ts:
   - Add `isValidating: boolean` to OptimizedJsonEditorState
   - Set `isValidating: true` at the start of setJsonText (when starting debounce timer)
   - Set `isValidating: false` when validation completes (in the setTimeout callback)
   - Initialize as false

2. In ValidationStatus.tsx:
   - Accept optional `isValidating` prop
   - When `isValidating && isValid`, show a subtle "Validating..." indicator with a small spinner or pulsing dot
   - Use gray/muted colors to be non-intrusive

3. In JsonEditable.tsx:
   - Pass `isValidating={state.isValidating}` to ValidationStatus

The indicator should be subtle - users shouldn't feel like validation is slow, just that the system is working.
  </action>
  <verify>Build passes: `pnpm build`</verify>
  <done>ValidationStatus shows subtle loading indicator during validation delay, disappears when validation completes</done>
