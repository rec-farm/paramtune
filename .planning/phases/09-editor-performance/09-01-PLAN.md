<objective>
Eliminate typing lag in the JSON editor by debouncing syntax highlighting and optimizing re-renders.

Purpose: The editor currently runs 8 regex patterns on every visible line for every keystroke. This causes noticeable lag when typing, especially in larger documents. By debouncing highlighting updates and stabilizing component renders, we restore responsive typing.

Output: Lag-free typing experience where syntax highlighting updates slightly after keystroke completion (50-100ms delay), while the textarea remains immediately responsive.
</objective>

**Performance bottleneck analysis:**

1. `SyntaxHighlightOverlay` recalculates on every `jsonText` change (line 25-28)
2. `highlightJsonVisibleLines` runs 8 regex patterns per visible line per keystroke
3. Cache key at line 64 of optimizedSyntaxHighlighter.ts includes line content, defeating cache for in-progress edits
4. No debounce - highlighting is synchronous with typing

**Strategy:**
- Debounce the syntax highlighting (not the textarea value)
- Keep textarea immediately responsive
- Delay overlay update by 50-100ms after typing stops
- Memoize visible lines slice to prevent array recreation

**Prior decisions:**
- 100ms debounce for autocomplete suggestions (from Phase 1)
- 300ms debounce for validation (established pattern)
- Pure TypeScript implementation (no external libraries)
</context>

This reduces work in SyntaxHighlightOverlay since it receives already-sliced content.

<task type="auto">
  <name>Task 3: Simplify cache key in highlightJsonLine</name>
  <files>src/components/JsonEditable/utils/optimizedSyntaxHighlighter.ts</files>
  <action>
The cache key (line 64) is:
`${line}-${Object.values(options).join('')}-${Object.values(theme).join('')}`

This is expensive and unstable (object key order not guaranteed). Simplify to:
1. Since options are rarely changed (defaults used), use a simple hash or skip options in key
2. Since theme is stable per render ('light' or 'dark'), use theme name directly
3. New key: `${line}-${themeName}` where themeName is 'light' or 'dark'

Modify `highlightJsonLine` signature to accept `themeName: 'light' | 'dark'` instead of `theme: SyntaxHighlightTheme`, and look up the theme inside.

This makes cache hits more effective when the same lines appear across renders.
