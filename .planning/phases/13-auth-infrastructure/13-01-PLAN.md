<task type="auto">
  <name>Task 2: Create BetterAuth server configuration</name>
  <files>src/lib/auth.ts, data/.gitkeep</files>
  <action>
Create `src/lib/auth.ts` with BetterAuth server configuration:

1. Create data directory for SQLite database:
   - Create `data/.gitkeep` to ensure directory exists in git
   - Add `data/*.db` to .gitignore if not already there

2. Configure BetterAuth in `src/lib/auth.ts`:
   - Use better-sqlite3 for primary storage (auth tables: user, session, account)
   - Configure Google OAuth provider
   - Use nextCookies plugin for cookie-based session management
   - Database path: `./data/auth.db`

Key configuration:
```typescript
import { betterAuth } from 'better-auth'
import { nextCookies } from 'better-auth/next-js'
import Database from 'better-sqlite3'

const db = new Database('./data/auth.db')

export const auth = betterAuth({
  database: {
    db,
    type: 'sqlite',
  },
  socialProviders: {
    google: {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    },
  },
  plugins: [nextCookies()],
})
```

Do NOT add Redis secondary storage in this plan - keep it simple. Session caching optimization can be added later if needed.

  </verify>

<task type="auto">
  <name>Task 3: Create auth API route handler</name>
  <files>src/app/api/auth/[...all]/route.ts</files>
  <action>
Create catch-all API route for BetterAuth at `src/app/api/auth/[...all]/route.ts`:

```typescript
import { auth } from '@/lib/auth'
import { toNextJsHandler } from 'better-auth/next-js'

export const { GET, POST } = toNextJsHandler(auth)
```

This creates endpoints for:
- GET /api/auth/session - Get current session
- POST /api/auth/sign-in/social - Initiate OAuth flow
- GET /api/auth/callback/google - OAuth callback
- POST /api/auth/sign-out - Sign out

The route uses Next.js dynamic segments ([...all]) to catch all auth-related paths.
