Create login page at `src/app/login/page.tsx`:

1. Use "use client" directive (needs client-side hooks)
2. Import signIn, signOut, useSession from lib/auth-client
3. Display based on session state:
   - If logged in: Show user info (name, email) and Sign Out button
   - If logged out: Show Sign in with Google button

Design requirements:
- Center the login card on the page
- Use existing Tailwind utilities from globals.css
- Match the glass card style used in dashboard (.card-glass)
- Include ParamTune logo or title
- Provide clear visual feedback for loading states

Button behavior:
- Sign in with Google: `signIn.social({ provider: 'google' })`
- Sign out: `signOut()`

Example structure:
```tsx
'use client'

import { signIn, signOut, useSession } from '@/lib/auth-client'

export default function LoginPage() {
  const { data: session, isPending } = useSession()

  if (isPending) {
    return <div>Loading...</div>
  }

  if (session) {
    return (
      // Show user info and sign out button
    )
  }

  return (
    // Show sign in with Google button
  )
}
```

Style the page to be visually consistent with the existing dashboard aesthetic.
