Update SchemaHistory component to support version restore:

1. Add onRestore to SchemaHistoryProps interface:
```typescript
interface SchemaHistoryProps {
  history: Array<SchemaHistoryEntry & { timestamp: number }>
  currentSchema?: SchemaHistoryEntry
  onRestore?: (content: Record<string, unknown>) => Promise<void>
}
```

2. Import useTransition from React and add state:
```typescript
const [isPending, startTransition] = useTransition()
```

3. Create handleRestore function:
```typescript
const handleRestore = (content: Record<string, unknown>) => {
  startTransition(async () => {
    if (onRestore) {
      await onRestore(content)
    }
  })
}
```

4. Add Restore button in the selected entry details panel (right side), after the header with version details. Only show when:
   - An entry is selected (selectedEntry exists)
   - It's NOT the current version (selectedIndex !== 0)
   - onRestore callback exists

Button styling:
```tsx
<Button
  variant="outline"
  size="sm"
  disabled={isPending}
  onClick={() => handleRestore(selectedEntry.content)}
>
  {isPending ? 'Restoring...' : 'Restore this version'}
</Button>
```

Place the button in the header area of the selected entry details, next to the timestamp badge, wrapped in a flex container.

Do NOT add confirmation dialog - restore is non-destructive (creates new version, history preserved).
